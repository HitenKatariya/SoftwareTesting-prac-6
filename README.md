 # Practical 6: Software Testing

## Aim
To design and execute test cases for a sample software application using black-box testing techniques.

## Random Information
- **Testing technique:** Equivalence partitioning and boundary value analysis
- **Sample application:** Student result calculator
- **Inputs tested:** Marks, attendance, and student identification number
- **Expected outcome:** Valid inputs produce accurate results, while invalid inputs display suitable error messages.
- **Tools:** Manual test-case table, spreadsheet, or any basic testing framework
- **Test status:** Passed after correcting invalid-input validation.

## Conclusion
The practical demonstrated how systematic test cases help identify defects and improve the reliability of software.
